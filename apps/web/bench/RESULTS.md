# Retrieval latency & scale benchmark

> Synthetic corpus (random 384-dim unit vectors + fixed-vocabulary text), isolated `bench_chunks` table with a real pgvector HNSW index + an ephemeral Elasticsearch index. Measures retrieval **latency** (not quality). 200 queries/scale after 20 warmup. Generated by `apps/web/bench/latency-bench.ts`.

Machine: local Docker (Postgres/pgvector, Elasticsearch 8, 512MB heap). Node v22.12.0.
